# 2026-10-19 公开查询界面更新

公开网页与扩展共用新版查询界面，沿用私人工作台的蓝橙色、圆角卡片和玻璃导航。根路径 `/` 为公开查询，私人入口仍为 `/workspace` 或 `/?workspace=1`；两者分别由独立 Worker 提供内容。

## 本次行为

- 今天、明天、后天快捷选择均按北京时间计算，跨月、跨年和闰年遵循日历日期。
- Ctrl / Command + Enter 提交查询，保留原生表单验证；输入法组合输入、禁用状态与进行中的请求不会触发新查询。
- 车站确认期间锁定表单，目录请求最多等待 8 秒；失败后恢复控件，允许重试。
- 查询、重新核验和 AI 发起查询展示骨架及进度；流式结果仍逐步显示，浏览器标题反映查询状态和当前有效方案数。
- 无结果、失败和过期状态可直接返回查询条件。页面定位与 CSS 动画遵循系统减少动态效果设置。
- 公开页面的直达、同车分段、异车中转、买长乘短和补票卡片有对应类型色条；具体票段和风险提示保留。
- 浏览器扩展更新至 1.0.1，日期与时间布局同步适配新容器。已有解压安装需替换扩展目录，再在扩展管理页重新加载。

## 验证

`npm run check`、改动 TypeScript 文件的 ESLint、143 项网页测试、12 项 Pages 转发测试、公开源码扫描和 `npm run build:public` 均通过。

浏览器使用合成数据检查了查询骨架、SSE 完成、筛选、重新核验、取消、失败恢复、车站超时恢复、AI 对话，以及 1440px、390px、320px 和减少动态效果。扩展专属样式下还核对了 390px 的日期与时间对齐。合成结果不代表实际车次库存。

## 发布

在自己的部署配置与授权就绪后执行 `npm run deploy:public`。该命令自动构建网页和扩展 ZIP；纯界面变更无需重新部署 Pages 桥接。部署后应从统一入口核对 HTML、CSS、JS 与扩展包，与本地构建一致。

完整资源配置和首次部署步骤见 [部署说明](deployment.md)。
