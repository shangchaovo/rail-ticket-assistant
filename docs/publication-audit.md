# 公开发布前审查

本次审查范围：当前源码、原本地 Git 全部历史 blob、助手 ZIP 及生成扩展；登录与任务拥有者隔离、公开/私人服务边界、AI 事实来源、固定请求目标、扩展权限和错误日志。敏感值不写入本报告。

## 已处理

- 公开发布使用新的干净 Git 历史；原私人开发历史、真实查询验收文档和截图未复制。
- Cloudflare 账号 / 数据库 ID 和 Sites 项目标识移除；本地部署覆盖文件被忽略。
- 排除 Cookie、浏览器 profile、环境文件、钥匙串、数据库、日志、诊断快照及现成二进制交付包；交付包可从源码重建。
- 公开网页请求强制省略凭据；Pages 公开分流额外剥离 Cookie、Authorization、助手租约及平台身份头。私人转发保留鉴权。
- 新口令配置采用随机 salt、100000 轮 PBKDF2-SHA256；旧摘要格式保留兼容读取，迁移顺序见部署说明。
- 增加相应隔离与密码格式回归测试、发布扫描和不需要生产 secrets 的 CI。

## 审查结果与限制

按本次检测规则，未发现真实明文密码、服务 token 或私钥进入公开源码。生产资源标识、查询记录和旧提交已从发布副本剥离。测试中的认证值为合成数据；manifest 中的 RSA key 为公开身份材料；公开车站与离线地理数据保留来源署名。

这是一轮源码及发布内容审查，不是第三方渗透测试，也不能证明历史上从未在其他渠道泄露。GitHub 公开发布只包含审查后的副本；本机原工程与生产配置仍由拥有者保管。
