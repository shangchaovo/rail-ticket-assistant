# Mac 查询助手 1.3.0

手机或电脑网页把查询送到云端队列；这台 Mac 在 12306 官方浏览器中正常查询，再上传已核验的车次、席别与区间结果。助手可以安装为当前用户的 macOS 后台服务，关闭终端后继续工作。电脑仍需开机、登录此 macOS 账号并保持联网；休眠、合盖、注销、关机或断网时无法查询。

1.3.0 增加一次同站异车中转，两段各按自己的内部车次、始发运行日与实际乘车日期核验。自动选有限候选枢纽，也可由网页指定中转站；比较官方票价与总用时，不依赖官网中转推荐列表。网站与助手需要同步更新；本版沿用 1.2.0 的 D1 结构，不需要新增迁移。此交付包的生成不代表网站已部署或后台服务已安装；安装命令只在本人运行后生效。

## 首次使用

1. 安装 Node.js 22 或更新版本。
2. 在网页的“连接电脑”界面生成设备令牌。
3. 双击 `setup.command`，选择云端类型（Cloudflare 填 `cloudflare`，Sites 填 `sites`），输入网站 origin，并粘贴设备令牌。预配置后直接按 Enter 接受默认类型和地址即可。令牌输入会隐藏，保存在 macOS 钥匙串。
4. 首次配置后，双击 `install-service.command`（或在助手目录运行 `npm run service:install`），安装并启动后台服务；之后登录这个 macOS 账号会自动启动，终端可以关闭。也可以双击 `start.command` 临时前台运行，按 Control+C 停止。两种运行方式不能同时启动；专用浏览器进程锁会拒绝第二个助手。

提交查询后，助手正常请求 12306 官网正在使用的余票接口。官网要求登录或验证时，会打开独立 Chromium 窗口；请由本人处理。

Cloudflare 网站只需要网页生成的设备令牌；网站登录密码由网页处理，不输入助手。Sites 网站还需要平台服务凭据：当前 Mac 如果已由安装工具预配，配置时无需再次输入；换另一台电脑时，需要通过拥有此 Site 的 Sites 工具取得并安全配置，网页不能读取或显示该平台凭据。所有远程网站必须使用 HTTPS；只有 localhost 调试允许 HTTP。

迁移网站时，安装工具先更新云端类型与地址；助手会清除原网站的设备令牌和服务凭据，需在新网页重新配对。Cloudflare 模式不会发送或保留旧 Sites 服务凭据。旧安装没有云端类型时继续按 Sites 处理。

登录、滑动或短信验证请直接在官方浏览器完成。助手会停止当前任务的后续区间请求、保留已确认结果并发出 Mac 系统通知。处理后在网页点“已处理，恢复助手”，或双击 `resume.command`（也可在助手目录运行 `npm run resume`）；前台也可按 Enter。确认后结束这一轮查询，需要新库存时请重新查询。后台无需交互终端；等待期间维持任务心跳，网页仍可取消任务。助手不会代答验证码、购买车票或提交候补订单。

定时盯票遇到官网限流、登录或验证后至少冷却 10 分钟，再按保存的间隔提交新一轮查询；等待本人处理期间不会同时创建另一轮任务。空闲助手每 10 秒领取一次云端任务。

出现可买且覆盖全程的直达、同车两段、异车中转或买长乘短方案时，每个任务最多发一条 Mac 通知；只有短票补票不会触发有票通知。Mac 通知由系统决定是否显示，请在 macOS 通知设置中允许脚本通知。网页之外的手机提醒需在网页配置提醒渠道，Mac 本机通知不会自动推送到手机。提醒只是这一次官网库存的发现，请购票前重新核验。

## 后台服务管理

在助手目录运行以下命令；安装无需管理员权限，不保存设备令牌到 plist。

```sh
npm run service:install
npm run service:status
npm run service:stop
npm run service:start
npm run service:uninstall
```

双击 `status-service.command` 可查看状态，`stop-service.command` 可停止后台服务。`service:stop` 会停止服务并禁用下次登录自动启动，`service:start` 再启用。安装或升级前先停止旧助手；修改配对后也要停止并重启，以读取新的钥匙串配置。服务绑定安装时的 Node 和助手绝对路径，移动文件夹或更新后删掉旧 Node 时，需要重新安装服务。

当前网络若必须走本人配置的 HTTP/HTTPS 代理，安装时显式设置 `NODE_USE_ENV_PROXY=1`、`HTTP_PROXY`、`HTTPS_PROXY` 与 `NO_PROXY`，并使用支持环境代理的 Node 版本。安装程序仅把这四项写入后台 plist，不继承其他环境变量；含账号密码的代理 URL 会被拒绝。关闭代理程序后后台可能无法连接云端，需要保持代理运行或重新安装无代理配置。

如需防止仅由空闲导致的系统睡眠，安装时运行 `npm run service:install -- --prevent-idle-sleep`，或前台运行 `npm start -- --prevent-idle-sleep`。该选项通过 macOS `caffeinate -i` 实现，不会防止合盖、手动休眠、关机、注销或断网；电脑实际休眠时任务和提醒都会暂停，网页会按心跳显示离线，过期任务需要重新查询。

服务配置位于 `~/Library/LaunchAgents/cn.rail-assistant.helper.plist`，本机状态与日志位于 `~/Library/Application Support/12306 Rail Assistant/runtime/`。`service:status` 显示进程、验证等待状态及日志路径。日志不记录凭据或 Cookie；本机恢复文件仅含一次性请求标识、任务标识、本人处理提示和时间，权限为本人可读写，等待结束后删除。异常退出后，进程锁可自动识别并清理已退出的旧进程；服务由 launchd 重新启动，同一浏览器不会由两台本机进程同时使用。

## 诊断与验证

双击 `diagnose.command`，检查 Node、Chromium、站名数据、钥匙串配置和云端只读健康接口。终端不会显示设备令牌、服务凭据或 Cookie。

开发验证命令：

```sh
npm ci
npm run browser:install
npm run check
npm test
npm run probe -- 2026-10-05 杭州东 温州南
```

`probe` 打开助手自己的专用浏览器，仅执行普通官方查询，写出 `probe-result.json`。文件只含经过归一化的车次、日期、席别与经停数据，不含官方预订密文或个人身份信息。该文件属于诊断快照，不是保证仍可购买的票源。

## 查询边界

- 余票和经停直接请求官网当前的查询接口，速度与在 12306 页面点一次查询相近。浏览器只负责保持访问状态；遇到验证时才显示窗口。
- 连续接口请求之间保留短暂间隔；遇到官方限流、验证码或请求预算用尽时停止当前任务后续区间请求并保留已确认方案。页面点击回退仍至少间隔 3 秒。相同区间在一次任务内复用快照；复查任务使用新快照。
- 可用、数字余票、无票、候补、未开售、不支持和未知状态分别处理。未成功读取数据不等于无票。
- 使用内部列车编号、始发运行日和站序确认同车；以区间历时核验跨午夜日期。无法核验时停止该区间规划。
- 初查读取官方正常查询响应所含票价；复查优先读取相同字段，必要时普通点击余票单元格展开并读取可见价格。缺失或异常的价格保持“待核验”，不估算补票金额。
- 官方改变字段或页面控件、网络故障、验证和限流均可能导致部分或全部查询不可用。

## 本机资料与安全

Cookie 留在 `~/Library/Application Support/12306 Rail Assistant/browser-profile`，不上传云端。设备令牌以及 Sites 模式需要的平台服务凭据留在钥匙串，账号 `rail-assistant`，服务名以 `cn.rail-assistant.` 开头；`provider` 保存 `sites` 或 `cloudflare`。云端只收到归一化余票、经停和规划结果。

助手只主动访问配置的固定网站和官方查询网站；云端请求不跟随重定向，不向另一地址转发授权头。没有对外监听端口，不需要路由器设置、扩展或内网穿透。前台关闭终端或按 Control+C 停止；后台用 `npm run service:stop` 停止。网页取消任务也会终止后续查询。

安装工具的隐藏 stdin 配置保留 `setup-site-stdin` 命令名：Cloudflare 预配置传入 `provider: "cloudflare"` 和 `origin`，不传 `serviceToken`；Sites 传入 `provider: "sites"`、`origin` 和平台服务凭据。`setup-stdin` 可在这些字段之外传入新网页生成的 `deviceToken` 完成配对。令牌不应放入命令参数或配置文件。

`shared/` 包含工程公共类型及规划器的打包副本；工程内执行 `npm run sync` 可同步更新。独立交付包没有父工程时沿用这些副本。

网页右下角和导航栏的“使用教程”逐项高亮讲解。地图里另有“地图教程”。本版批量读取地图缓存，复用浏览器与站名表，合并进度上传；余票快照仍按每次任务隔离，重新核验会查新库存。官网仅返回同城其他车站时，会列出实际站点组合供重新查询，所选区间保持未确认。
