# 同车余票 · 浏览器扩展 1.0.0

适用于 Chrome 116+ 和支持 sidePanel API 的新版 Edge。扩展尚未上架浏览器商店，当前提供本地加载包。

## 安装

1. 将压缩包解压，保留整个 `rail-browser-extension` 文件夹。
2. Chrome 在地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开页面上的“开发者模式”，点“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `rail-browser-extension` 文件夹。
4. 在工具栏的扩展菜单中固定“同车余票 · AI 查票助手”。点击图标即可打开侧边栏。

安装完成后保留文件夹；移动或删除它会使扩展无法加载。升级时用新版内容替换此文件夹，再在扩展管理页点击重新加载；当前 manifest 公钥保持扩展 ID 稳定。

## 使用

- 侧边栏可以直接填写实际车站、日期、人数与席别，查询直达、同车两段、一次同站中转。
- 点击“AI 查票助手”或“AI 帮我查票”，例如输入“明天杭州东到温州南，2 人，18 点前到，预算每人 180，便宜优先”。未提及的条件沿用表单。
- AI 只比较本轮已核验的候选，回答附真实采集时间。有效期最多 5 分钟，过期后重新查；追问仍有效的结果不会重复查官网。
- 每张实际票段可分别打开带站名和日期的 12306 余票页。进入官网后自行选择对应车次、核对席别并购买。工具不会下单或提交候补。
- “私人工作台”在普通网页中新开，使用网站原有私人密码。私人查询和盯票仍使用原 Mac 助手。
- 切换浏览器标签时，侧边栏可继续使用。关闭侧边栏后不保留正在进行的查询；重新打开应查新库存。

## 权限与数据

只申请 `sidePanel` 和本站 `https://rail-same-train-pages.pages.dev/*` 的连接权限。没有内容脚本，不申请 cookies、tabs、scripting、浏览记录或所有网站权限；不读取当前网页或 12306 Cookie。官网入口只是正常新标签页链接。

公开查询使用现有 Cloudflare 服务与匿名官方查询数据源，无需另开本地程序。服务器与官网不可用、验证、限流或额度不足时会停止并说明原因；本扩展不保证遍历全部路线或购票成功。

公开网页和扩展共用每网络每天 20 次、全站 100 次查询额度；AI 每网络每天 15 条、全站 50 条，仍使用账户现有的模型额度。消息与检索后的归一化票段交给本站 Cloudflare 模型处理，不把 Cookie、原始官网响应或设备令牌交给模型。对话仅在当前侧边栏内保留，不设置长期库存库。

云端服务由该项目维护，费用和额度按其部署配置计算；本包不包含个人密码、模型 Key 或后台密钥。

## 故障与卸载

- 没有打开侧边栏：先更新 Chrome / Edge，再到扩展管理页查看是否有加载错误。
- 服务不可用或额度用尽：稍后再试，或从官网链接自行查询；不要持续刷新。
- 在扩展管理页点“移除”即可卸载。本扩展没有安装本地守护程序。

接口、权限和侧边栏实现参考 [Chrome sidePanel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)、[扩展网络请求](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)、[本地加载教程](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。
